YOUR AI. IN YOUR BROWSER.

Your browser.
A little more capable.

Read a page, write a draft, fill a form, or work through a task. Bring your own model and API key. Review every action before it runs.

01

Open Chrome’s Extensions page

Type chrome://extensions in Chrome’s address bar. Turn on Developer mode at the top right.

02

Load the extension folder

Click Load unpacked. Choose the extension folder inside this extracted orbit-chrome folder. It contains manifest.json.

03

Connect your AI

Pin Orbit in Chrome and click its icon. Open settings, choose your provider, paste your API key, and choose a text/chat model. Click Save connection.

04

Ask for a helping hand

Open a website and send a request. Approve site access when needed. Use Ask for answers, or Assist for reviewed browser actions.

You’re in control. Every edit, click and tab action needs approval. Keys last for this browser session unless you choose to remember them on this device. Visible page context is sent directly to your chosen provider when used.

Model support: OpenAI Responses, OpenAI-compatible Chat Completions, Claude, Gemini, and local Ollama. Add custom endpoints and exact model IDs in settings. Models with other proprietary APIs need an adapter; not every model can perform browser tasks.

Validation: 40 automated tests passed. Live Chrome and real API testing still need verification on your machine. Browser-internal pages, frame/canvas editors, file pickers and protected controls have limits.
